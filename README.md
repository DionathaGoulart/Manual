## 🛠️ Getting Started

### Prerequisites

*   **Node.js 18+**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/DionathaGoulart/Manual.git

# 2. Enter the directory
cd Manual/Vextro

# 3. Install dependencies
npm install
npm run dev
```
